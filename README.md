SMART WAYS(A Smart Traffic Management System)
Smart Traffic Management System using Machine Learning (Smart Ways) is a mini project developed as part of the B.Tech CSE curriculum under KTU. The system aims to reduce traffic congestion and improve signal efficiency by dynamically adjusting traffic light timings based on real-time vehicle count and speed data. Using a modified Priority Round Robin (PRR) algorithm with dynamic quantum time, Smart Ways ensures fair and efficient signal distribution while prioritizing emergency vehicles. The project integrates technologies like Golang, Python, MongoDB, and TensorFlow, along with LSTM models for traffic prediction and YOLOv11 for real-time vehicle detection. A real-time web interface built with HTML, JavaScript, and Canvas simulates junction activity and allows manual controls.
